# AGENTS.md


The website for **Creative Coding Kortrijk (CCK)**, built with [Astro](https://docs.astro.build) 7. It is a static site whose content lives in Markdown content collections.

This is a group project for school (Devine, WEB3, "git party"). Several people work in the same repo, so keeping the Git history clean matters as much as the code does.
