## Project
- A fun website about the new creative code club in Kortrijk.
- Audience: anyone interested in creative code.
- Language: [Dutch / English]

## Stack & constraints
- Astro [7.4.2]
- Pages in `src/pages/`, layouts in `src/layouts/`, components in `src/components/`
- Content collections in `src/content/` ([collection names, e.g. `events`, `members`])
- Styling: plain CSS, no CSS framework
- Package manager: [npm / pnpm]; dev: `[npm run dev]`, build: `[npm run build]`
